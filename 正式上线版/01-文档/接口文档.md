# 亏了 · 后端接口文档

> **给谁看的**：写前端的人（或帮小白对接的人）。
> **基础地址**：`https://api.你的域名`

---

## 一、通用约定

### 1.1 请求格式

所有接口都是 `POST` 或 `GET`，参数用 **JSON** 传（`GET` 用 query string）。

```
Content-Type: application/json
Authorization: Bearer <token>     ← 除标注「免登录」的接口外都要带
```

### 1.2 返回格式

**成功：**
```json
{ "code": 0, "msg": "ok", "data": { ... } }
```

**失败：**
```json
{ "code": 40001, "msg": "写一个标题吧", "data": null }
```

> `code = 0` 表示成功，其他都是失败。`msg` 是**可以直接展示给用户的中文提示**。

### 1.3 错误码表

| code | 含义 | 前端怎么处理 |
|---|---|---|
| 0 | 成功 | — |
| 40001 | 参数不对 | 直接显示 `msg` |
| 40100 | 未登录 | 清 token，重新登录 |
| 40101 | 登录过期 | 清 token，重新登录 |
| 40300 | 无权限 | 显示 `msg` |
| 40400 | 资源不存在 | 显示 `msg` |
| 40900 | 状态冲突（如重复打卡） | 显示 `msg` |
| 50000 | 服务器内部错误 | 提示「请稍后再试」 |
| 50200 | 微信接口错误 | 显示 `msg` |
| 50300 | AI 服务错误 | 显示 `msg` |


**校验规则（后端会再校验一遍，前端校验只是体验优化）：**

- 周期只能是 7/14/30/90

- 新人保护：第 1 个 Flag（7/14 天）自动免押金

## 七、支付 ` /api/pay `

### 7.1 创建支付订单

```
POST /api/pay/create
```
**Body：** `{ "flagId": "flg_a" }`

**返回（内测阶段 `DEPOSIT_ENABLED=false`）：**
```json
{
  "code": 0,
  "data": {
    "free": true,
    "beta": true,
    "amount": 0,
    "nominalAmount": 500,
    "message": "内测阶段，暂不收取押金"
  }
}
```

> **🆕 `beta: true` = 内测阶段暂不收取押金。**
>
> 服务器**不创建订单、不调微信支付**，但已把这一局标记成「押金已支付（内测免收）」，
> 状态不会脏。
>
> 字段含义：
> - `beta: true` —— 内测标志
> - `amount: 0` —— **实收**金额（没收到钱，所以是 0）
> - `nominalAmount` —— **名义押金**（这一局「本来要押多少」，照常记录）
>
> 前端拿到 `beta` 后**不要调 `wx.requestPayment`**，
> 弹 `wx.showModal({ title: '内测阶段', content: '内测阶段，暂不收取押金', confirmText: '知道了' })`，
> 点「知道了」后正常跳转目标详情页。
>
> **⚠️ 前端不要用本地缓存的 `depositEnabled` 做分支判断** ——
> 缓存可能过期，导致「服务器要收钱、前端却跳过支付」，用户的押金永远收不到。
> **以本接口返回的 `beta` 为准。**

**返回（正式阶段，需要支付）：**
```json
{
  "code": 0,
  "data": {
    "beta": false,
    "free": false,
    "orderId": "ord_xxx",
    "outTradeNo": "KL202611261200001234",
    "amount": 1000,
    "payParams": {
      "timeStamp": "1793000000",
      "nonceStr": "abc123",
      "package": "prepay_id=wx123456",
      "signType": "RSA",
      "paySign": "..."
    }
  }
}
```

**返回（新人保护免押金）：**
```json
{ "code": 0, "data": { "beta": false, "free": true, "amount": 0 } }
```

**前端调起支付：**
```js
wx.requestPayment({
  timeStamp: d.payParams.timeStamp,
  nonceStr: d.payParams.nonceStr,
  package: d.payParams.package,
  signType: d.payParams.signType,
  paySign: d.payParams.paySign,
  success() { /* 支付成功 */ },
  fail() { /* 用户取消或失败 */ },
});
```
