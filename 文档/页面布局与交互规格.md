## L0设计基线

> 视觉语言、尺寸基线 —— 颜色、圆角、字号、间距、阴影、触控目标的全套取值。所有页面都从这里取值 —— 写样式前先定基线，不要在页面上临时发挥。

### L0.1视觉语言

| 键 | 值 |
|---|---|
| 整体调性 | 暖白底 + 高饱和亮橙主色。不做冷色金融风，不做扁平灰 —— 要有「消费类打卡产品」的亲和力 |
| 主色 | 品牌橙 —— 用于主按钮、进度、强调、金额数字 |
| 强调色 | 朱橙红（目标/热度）· 金橙（提醒/进行中）· 天蓝（信息）· 亮紫（见证）· 正红（失败/危险）· 亮绿（达成） |
| 中性色 | 暖白系四档：页面底 / 卡片面 / 次级面 / 分隔线 |
| 圆角 | 8 / 12 / 16 / 20 / 26 / 999px六档，全局统一 |
| 阴影 | 暖调（带橙棕偏移，不用死黑），两档 |
| 数字 | 全局用等宽数字字型，字重700–750，字距收紧 |






### L0.2尺寸基线

| 键 | 值 |
|---|---|
| 字号阶梯 | 主体15px → 次级13px → 辅助11px → 标签10.5px；大金额17–22px；倒计时40px等宽 |
| 间距阶梯 | 区块间22px → 卡片内12–14px → 元素间8–10px → 行内4–6px |
| 圆角阶梯 | 输入框/小卡12px → 卡片16px → 大卡20px → 主卡26px → 胶囊999px |
| 触控目标 | 主要按钮高42–48px，图标按钮 ≥ 30×30px |
| 页面边距 | 左右16–18px |

## L3广场卡片与瀑布流

> 广场卡片与双列瀑布流的规格 —— 卡片尺寸、封面图、计数条、瀑布流列宽与间距。窄栏放不下「图标 + 文字 + 数字」 —— 计数一律只留图标 + 数字。

### L3.1瀑布流实现

（必读）用Grid，不用CSS `columns`。这是排序正确性问题，不是样式问题。

```
CSS `columns`（column-count: 2）**「先填满第1列再填第2列」，用户从左到右扫时跨列的先后关系被破坏 —— 广场是按优先级排序的（强见证 / 即将结算 / 进行中优先），顺序错了信息就错
```

| 键 | 值 |
|---|---|
| Grid + `align-items: start` | 各自贴顶，瀑布流，不同行卡片互不拉伸，顺序与DOM一致 |






### L3.2卡片尺寸

| 键 | 值 |
|---|---|
| 栏宽 | 窄栏153–173px区间（双列），窄栏放不下大字 |
| 封面 | 3:4竖图 |
| 标题 | 13px / 2行 |
| 体重 | 17px（保持视觉锚点，但收小） |
| 数据条 | 起始体重 → 目标体重｜监督人数（眼睛图标）｜进展条 |
| 进展条 | 3px细条 + 单行文字（砍掉右侧重复的「90天」） |
| 头像 | 28px + 名字（状态比名字更重要） |
| 底部操作行 | 点赞 / 留言 / 监督 —— 纯图标 + 数字，无文字 |






> （边界）窄栏放不下三个「图标 + 文字 + 数字」，所以操作行是纯图标 + 数字。

### L3.3广场不设缩略图条

（边界）广场没有8格缩略图条。窄栏塞8个格子，每格不到20px，比「噪音」还糟。那套格子样式一字不改地留着，异议页与物证详情页还在用。

### L8.1信用等级色

五档五色，必须可区分。

| 等级 | 信用分 | 语义色 | 视觉 |
|---|---|---|---|
| 受限 | 45–59 | 玫红（危险） | 玫红底 |
| 普通 | 60–69 | 琥珀（提醒） | 琥珀底 |
| 良好 | 70–79 | 天蓝（信息） | 天蓝底 |
| 优秀 | 80–89 | 薄荷绿（进阶） | 薄荷绿底 |
| 卓越 | 90–100 | 品牌橙（最高） | 品牌橙底 |






> （必读）五档必须是五个不同的颜色。「良好」和「优秀」如果共用同一个天蓝，70分和80分在页面上看起来一模一样，但押金上限差一倍（1000 vs 2000）、失败扣收差5个点（30% vs 25%），用户完全看不出自己处在哪一档。

### L12.15记录卡的文案约束

（必读）挣了的记录卡必须体现「骄傲」。

失败的结局配中性过程叙述（「我按自己的方式记录了30天」）是配得上的—— 用户没做到，坚持本身值得记。但

挣了的结局不同：用户赢回了押金、达成了目标，卡片应该让他骄傲。所以两种结局各有一套文案口径：

| 结局 | 标题 | 核心表达 |
| 挣了 | 「我说到做到」 | 押金全额拿回+ | 目标达成+ | 有人见证—— 三件骄傲的 |

### L12.16「确认并支付」金额选项的版式

卡片内元素顺序金额→说明文字→选中圈（圈在卡片最下面）

卡片排版纵向排列；金额顶部对齐、选中圈贴底对齐

金额文字居中（「dep-v」{ text-align:center }）

说明文字排在金额与圈之间（「首次免费」「信用分不够」）—— 它是金额的注解，不是卡片底部的附注

卡片高度统一（所有档位等高）

（边界）选中逻辑不变 —— 只是版式调整，选中态、金额、说明文字的取值逻辑全部不变。

（边界）押金档位卡的金额顶部对齐、选中圈贴底 —— 实现用「金额顶部对齐+ 圈margin-top:auto贴底」，一排圆圈
