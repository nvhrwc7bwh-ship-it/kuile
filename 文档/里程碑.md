## M2.5 App 开发（新增，2026-11-16）

> **架构：App 为主 + 小程序作引流壳。M2.5 是飞轮闭合的关键阶段 —— 推送能力在此到位。**

- [ ] **⭐ 包名 / Bundle ID 定死**（`com.xxx.lede`）—— **上架后不可改**
- [ ] **⚠️ 确认有 macOS + Xcode**（iOS 打包必需）
- [ ] App 端全 40 页（复用后端 API 与设计规范 token，**不复用小程序 UI**）
- [ ] **⭐ 推送通道接入 —— 腾讯云移动推送 TPNS**（`tpns_flutter_plugin`）
    - 覆盖 华为 / 荣耀 / 小米 / OPPO / vivo / 魅族 / APNs
    - **必须正确配置厂商「消息分类」**（配错会被降级，推送不及时或收不到）
    - **华为 / 荣耀必须配置证书指纹**
    - **OPPO / vivo 有消息分类新规**，按「系统消息 / 重要消息」申请
    - 推送内容分级：断卡 / 判负 / 结算 = 强推送必达；每日提醒 = 弱推送可降级
    - 降级策略：厂商通道失败 → App 内轮询 + 首页红点
    - **到达率 / 点击率埋点**（召回效果的唯一度量）
- [ ] **App 端内容安全自建**（图片鉴黄 + 文本审核 + 人工兜底）—— App 推送与分享不走微信审核
- [ ] 离线存档 + 完整称重历史（sqflite 打卡队列）
- [ ] **引导装 App 的转化链路**（小程序 → App，含归因）
- [ ] **支付架构位预留**（`payment` 可插拔接口 + `pledge`/`order` 表建好但不写入；协议里埋好资金条款位置）
