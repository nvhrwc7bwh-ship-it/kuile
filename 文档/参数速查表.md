# 亏了 · 参数速查表

## 1 周期与节点

> 这一章是**整份表的地基** —— 所有「按周期缩放」的数字（打卡日、结束日、判定节点数、断卡额度）都在这里定，后面每一章引用周期时都以本章为准。
> **什么时候查**：只要你看到某个规则写着「按周期」「随天数变化」，就回这一章对号入座。
> **注意**：**结束日由周期算死、不可自定义**；断卡额度只认周期档位，不认任何别的时长。

### 1.1 周期 → 打卡日 / 结束日 / 判定次数

| 周期 | 打卡日总数 | 结束日 | 见证席判定次数 |
|---|---|---|---|
| **7 天** | 第 1 ~ 7 天 | 生效日 + 6 天 | **2 次** |
| **14 天** | 第 1 ~ 14 天 | 生效日 + 13 天 | **3 次** |
| **30 天** | 第 1 ~ 30 天 | 生效日 + 29 天 | **4 次** |
| **90 天** | 第 1 ~ 90 天 | 生效日 + 89 天 | **4 次** |

### 1.2 日期计算口径

| 项 | 规则 |
|---|---|
| **生效日** | 发起当天 + 24 小时（筹备期结束时） |
| **第 1 天** | 生效日 |
| **第 N 天** | 生效日 + (N - 1) 天 |
| **结束日** | 生效日 + (周期 - 1) 天 |

## 2 强度档位 T0–T3

> 这一章回答一个问题：**「有几个人在给我背书」这件事，换算成数字是多少** —— 档位、系数、背书强度、广场权重，以及**有效档位只降不升**怎么算。
> **什么时候查**：算信用分、生成记录卡标注、决定广场排序权重时。
> **注意**：**降档不触发任何资金追缴** —— 押金完全不受档位影响。

### 2.1 强度分级

| 强度 | 见证席数 | 押金 | 信用分系数 | 记录卡背书 | 广场权重 |
|---|---|---|---|---|---|
| **T0 独自打卡** | **0 位** | **不影响** | **× 0.6** | 标「独立打卡」 | 不进推荐位 |
| **T1 轻见证** | **1–2 位** | **不影响** | **× 0.8** | 显示 1–2 人头像 | 常规 |
| **T2 标准见证** | **3–4 位** | **不影响** | **× 1.0** | **完整背书** | 常规 |
| **T3 强见证** | **5 位以上** | **不影响** | **× 1.0** | 完整背书 + **优先推荐** | **加权** |

### 2.2 强度系数（成功 / 失败）

| 强度 | 见证席数 | 成功得分系数 | 失败扣分系数 |
|---|---|---|---|
| **T0 独自打卡** | 0 位 | **× 0.6** | **× 0.6** |
| **T1 轻见证** | 1–2 位 | **× 0.8** | **× 0.8** |
| **T2 标准见证** | 3–4 位 | **× 1.0** | **× 1.0** |
| **T3 强见证** | 5 位以上 | **× 1.0** | **× 1.0** |

### 2.3 档位影响范围

| 项 | 是否随有效档位变化 | 说明 |
|---|---|---|
| **信用分系数** | 变 | 成功加分与失败扣分都乘有效档位系数 |
| **记录卡背书** | 变 | 档位降 → 背书强度降 |
| **广场权重** | 变 | 档位降 → 推荐权重降 |
| **押金** | **完全不变** | 档位降档不触发任何资金追缴 |

### 2.4 分值取值时点

| 分值 | 用哪一档 |
|---|---|
| **中期到账** | 该笔到账时的有效档位 |
| **结束结算**（成功加分 / 失败扣分） | 结束时的有效档位 |

### 2.5 降档示例

| 场景 | 节点 1 | 节点 2 | 节点 3 | 节点 4 | 有效档位 | 结束系数 |
|---|---|---|---|---|---|---|
| 邀 10 人，只有 3 人点 | T2 | T2 | T2 | T2 | **T2** | ×0.8 |
| 邀 10 人，8 人认真判 | T3 | T3 | T3 | T3 | T3 | ×1.0 |
| 邀 5 人，节点 3 掉到 2 人 | T3 | T2 | T1 | T2 | **T1** | ×0.8 |
| T0（无见证席） | T0 | — | — | — | T0 | ×0.6 |

### 2.6 不乘系数的分值

| 分值 | 是否乘系数 | 理由 |
|---|---|---|
| 自己的 Flag 成功加分 | 乘系数 | 有没有人看着，决定这事值多少 |
| 自己的 Flag 失败扣分 | 乘系数 | 同上 |
| **被判负（作弊成立）-30** | 不乘 | 作弊跟有没有人见证毫无关系 |
| **见证席误报 -8 / 监督席异议不成立 -8** | 不乘 | 举报 / 异议是监督行为 |
| **打卡里程碑 +1** | 不乘 | 象征性分值 |
| **见证席 / 监督席全部分值** | 不乘 | 衡量见证人干得好不好 |

### 2.7 记录卡强度标注

| 强度 | 记录卡标注 | 头像墙 |
|---|---|---|
| **T0 独自打卡** | **标「独立打卡」** | 不显示头像墙 |
| **T1 轻见证** | 显示见证席人数（1–2） | 显示 1–2 人 |
| **T2 标准见证** | **完整背书** | 完整头像墙 |
| **T3 强见证** | 完整背书 + **优先推荐标记** | 完整头像墙 |

## 4 见证席判定与结算

> 这一章是**见证席的完整判定链路** —— 判定四态、聚合门槛、结算对照表、结算时限、成立率校准、加入门槛与生命周期。
> **什么时候查**：写见证席面板、算判定分值、判断节点能不能生效时。
> **注意**：**4.9 结算对照表是分值的唯一真相源** —— 别处出现的分值都以它为准。

### 4.1 判定 4 状态

| 状态 | 含义 | 是否表态 | 是否算「已判定」 |
|---|---|---|---|
| **通过** | 认为物证合规、进度真实 | 是 | 是 |
| **存疑** | 不确定（看不懂物证 / 不认可这个 Flag / 私人原因） | 是 | 是 |
| **作弊** | 确认他在糊弄（= 举报，理由选填） | 是 | 是 |
| **未响应** | 48h 窗口过了，什么都没做 | 否 | 不算 |

### 4.2 表态 vs 未响应

| | 表态了（通过 / 存疑 / 作弊） | 未响应 |
|---|---|---|
| 连带责任 | 仅判「通过」且事实造假时承担 -5 | 不承担 |
| 信用分 | 通过 +2 / 作弊 +3 / 存疑 0 | 0 |
| 加分 | 通过 +2 / 作弊 +3 | 不加 |
| 累计惩罚 | 判错 -8（最重） | 累计 3 次 → 丢见证席资格 |

### 4.3 延迟公示

| 时点 | 可见范围 |
|---|---|
| 判定窗口内（48h） | 只见自己的判定 + 见证门槛进度，不见他人判定 |
| 窗口关闭 → 结算完成 | 一次性公示该节点所有见证席的判定 + 分值变化 |

### 4.4 聚合定义

| 术语 | 含义 |
|---|---|
| **应到人数** | 该节点锁定名册中的见证席人数（24h 定档时锁定，全周期不变） |
| **已判定数** | 通过 + 存疑 + 作弊（表态即算） |
| **未响应数** | 应到人数 − 已判定数 |
| **见证门槛** | min(应到人数, max(2, ceil(应到人数 × 50%))) |

### 4.5 见证门槛检查

| 情形 | 处理 |
|---|---|
| **已判定数 ≥ 见证门槛** | 节点判定生效，按下表聚合 |
| **已判定数 < 见证门槛** | 该节点降级为「仅平台审核」 |

### 4.6 门槛约束范围

| 判定 | 是否受门槛约束 |
|---|---|
| **「通过」** | 受约束 |
| **「存疑」「作弊」** | **不受约束**（≥1 人表态即直接转人工复核） |

### 4.7 聚合结果（结算结果）

| 情况 | 结果 | 见证席结算 |
|---|---|---|
| 已判定者全部「通过」 | 正常 | 判「通过」者 **+2** |
| 已判定者中少数「存疑」 | 直接转人工复核 | 判「通过」者 **+2**；判「存疑」者 **0** |
| ≥1 人「作弊」+ 人工复核坐实 | Flag 判负（立即） | 判「作弊」者 **+3**；判「通过」者 **-5**；判「存疑」者 **0**；未响应者不受连带 |
| ≥1 人「作弊」+ 人工复核不成立 | 不判负 | 判「作弊」者 **-8**；判「通过」者 **+2**；判「存疑」者 **0** |
| 已判定者全部「通过」+ 事实作弊成立 | Flag 判负 | 判「通过」者 **-5**；未响应者不受连带 |

### 4.8 门槛满足 vs 降级

| 环节 | 见证门槛满足 | 见证门槛降级 |
|---|---|---|
| 谁裁决事实 | 见证席判定 + 人工复核 | 纯平台审核 |
| 审核怎么触发 | 判「作弊 / 存疑」→ 直接转人工；全「通过」→ 随机抽检 5–10% | 随机抽检 5–10% |
| 事实结论 | 人工给出 | AI 筛查 + 人工给出 |
| 见证席结算 | 走 4.9 对照表 | 走 4.9 对照表 |

### 4.9 结算对照表（分值唯一真相来源）

| 判定 | 事实结论 | 分值 |
|---|---|---|
| 通过 | 物证合规 | **+2** |
| 通过 | **物证造假** | **-5** |
| 作弊 | 造假成立 | **+3** |
| 作弊 | 不成立 | **-8** |
| 存疑 | 任意 | **0** |
| 未响应 | 任意 | **0** |
| 通过（见证门槛降级） | 平台审核判定合规 | **+2** |
| 通过（见证门槛降级） | 平台审核判定造假 | **-5** |
| 作弊 / 存疑（见证门槛降级） | 无强制复验 | **0** |
| 任意（见证门槛降级 + 7 天未审核） | 平台无法证明有问题 | **+2** |
| 通过（该节点有监督席异议 ≥3 票） | 系统已预警 → 物证造假 | **0** |
| 通过（24h 异议窗口内被提异议 → 重审坐实造假） | 系统已预警 → 物证造假 | **0** |

### 4.10 结算时限

| 路径 | 结算时限 | 是否需要告知 |
|---|---|---|
| **AI 筛查通过** | **最多 1 小时** | 否 |
| **进入人工复核** | **24 小时内**出结论 | 必须主动告知 |
| **24h 异议窗口** | 人工出结论后开窗，窗口时长 24h | 告知结论已出 |
| **窗口内有人提异议** | 转人工重审，再 24 小时内出结论 | 告知处于重审中 |
| **发起人申诉中** | 申诉期 24h 结束后再算 | 告知处于申诉期 |
| **见证门槛降级** | 与普通路径同一套时限 | 必须主动告知 |
| **兜底** | 提交满 7 天事实未定 → 按「通过」**+2** 结算 | 告知 |

### 4.11 判定质量校准（成立率）

| 项 | 规则 |
|---|---|
| 作弊判定配额 | 每见证席每周期有上限（如每月 3 次），超出的不进入统计 |
| 成立率 < 60% | 「作弊」判定失去加分效力（仍可用于 Flag 判负） |
| 成立率 < 60% | 「通过」判定同样失去加分效力 |
| 被复核推翻 | 扣分 + 计入成立率分母 |
| 计数时点 | 分子分母都只在结算时计数 |

## 10 状态机与结局

> 这一章把**结局相关的数字收在一处** —— 三种失败原因、成功判定条件、两种公开形态、结算三时点、结局产出、断卡软惩罚、记录卡的构成与分享。
> **什么时候查**：写状态机、出记录卡、判断某个时点该发什么时。
> **注意**：**失败也出记录卡、也永久留痕** —— 失败记录不可删除。

### 10.1 三种失败原因

| 失败原因 | 触发时机 | 押金 | 记录卡 | 信用分 |
|---|---|---|---|---|
| **断卡用尽** | 随时（第 N+1 次断卡当天） | 按失败扣收 | 未达标卡（照样出图） | 按周期扣减 × 系数 |
| **到期未达标** | 周期结束 | 按失败扣收 | 未达标卡 | 按周期扣减 × 系数 |
| **判负（作弊成立）** | 立即（不等周期结束） | 按失败扣收 | 未达标卡 | **固定 -30**（不按周期、不乘系数） |

### 10.2 成功判定条件

| # | 条件 |
|---|---|
| 1 | 结束称重体重 ≤ 目标体重 |
| 2 | 未用尽断卡容忍次数 |
| 3 | 三个称重节点判定通过 |

### 10.3 两种公开形态

| 状态 | 公开形态 |
|---|---|
| 成功 | 记录卡（达标） |
| 失败 | 记录卡（未达标），照样出图、照样可分享 |

### 10.4 只有两个结局

| | 达标 | 失败 |
|---|---|---|
| 记录卡 | 生成（达标形态） | 生成（未达标形态） |
| 押金 | 100% 全额退还 | 按信用等级扣收，剩余全额退还 |
| 信用分 | 分段到账 | 扣分 |
| 广场永久留痕 | 留 | 留 |

> 结局只有达标 / 失败两个。中途没有主动退出通道；断卡用尽、到期未达标、作弊判负三条路径都归入「失败」，失败原因需区分标注。

### 10.5 结算三时点

| 时点 | 触发 | 产出 |
|---|---|---|
| 中期到账 | 14 天第 7 天 / 30 天第 7 天 / 90 天第 7 天与第 30 天（7 天无） | 只发分数（+5 / +10），不出记录卡 |
| 结束结算 | 周期结束（成功 / 失败） | 发分数 + 生成记录卡 |
| 见证席节点结算 | 每个节点判定完成后 | 只发分数（+2 / +3 / -8 / -5） |

### 10.6 结局产出汇总

| 结局 | 产出 |
|---|---|
| **成功** | 记录卡（达标）+ 信用分分段到账（7 天 +5 · 14 天 +5 +5 · 30 天 +5 +10 · 90 天 +5 +10 +20） |
| **失败** | 记录卡（未达标）+ 信用分扣分（7 天 -5 / 14 天 -5 / 30 天 -10 / 90 天 -20）；作弊判负固定 -30 |
| **争议** | 24 小时申诉期 + 平台人工复核 |

### 10.7 中期到账前提

| # | 前提 |
|---|---|
| 1 | 该时点前无断卡 |
| 2 | 该 Flag 未被判负 |

### 10.8 断卡软惩罚（超出额度前）

| 层 | 惩罚 | 可见位置 |
|---|---|---|
| ① | 连续天数归零 | 首页 / 详情页 / 记录卡 |
| ② | 广场降权 | 广场信息流 |
| ③ | 打卡日历标红 | 打卡日历 / 记录卡 |
| ④ | 中期到账那笔不给（已给的保留） | 信用分明细 |
| ⑤ | 危险区强提示 | 首页 + 详情页 |

### 10.9 记录卡的构成与分享

| 项 | 规则 |
|---|---|
| **海报容器** | `.rc-poster` —— 凭据主体 + 4 个互动计数 + 品牌落款**合成一张图** |
| **互动计数** | 点赞 / 留言 / 监督 / 见证席 —— 四项都在卡上 |
| **档位标签** | **T1 不显示**（信息量由见证席计数承担）；只留 T0 / T2 / T3 |
| **品牌徽标** | 卡头右上角 —— 柴犬头像（狗头形象，套白色圆片底）+「亏了」，半透明白底 + 白描边 |
| **品牌落款** | 卡底 —— 柴犬头像（狗头形象）+「亏了」+「公开立目标，熟人见证」 |
| **落款红线** | 只写**机制**，不写**效果承诺** |
| **分享入口** | 点「分享这张记录卡」→ **就地升起分享半屏，不跳独立页面** |
| **分享面板** | 顶部 = 那张海报本身（所见即所得）· 提示 = 长按可保存/转发 · 底部 = 4 个渠道 |
| **分享渠道** | 微信好友 / 朋友圈 / 小红书 / 保存图片 |
| **缩放规则** | 按可用高度**等比缩小**，整张一次露全，**绝不截断** |
| **小红书版** | 不带码、不提微信，只提品牌词「亏了」 |
