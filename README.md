# 亏了

> 公开立减肥目标，全网见证，失败留痕。

**应用商店副标题**：`公开立减肥目标，失败留痕`

> **⚠️ 2026-11-20 品牌改名「立了」→「亏了」。**
> 「立 Flag」作为**动作词**保留不变；「立据」作为**机制词**保留不变。
> 改名理由：「立了」只覆盖"发起"这个免费动作，而产品最重的一段是「代价 / 不可逆 / 留痕」；
> 且「亏了」是**结果**而非陈述 —— 传播时别人接得住话（详见 `想法演进.md` 2026-11-20）。

## 一句话定位

一个只做减肥体重的微信小程序：公开立目标、每天提交带物证的打卡、由**受邀的熟人**当见证人在几个节点签字作证（**节点数按周期定：7 天 2 个 / 14 天 3 个 / 30 天 4 个 / 90 天 4 个**），**陌生路人只能围观和提出异议、永远不能判定**；失败会被永久记录并扣信用分。

> **⚠️ 2026-11-17 更正**：早期版本写的是"全网陌生人当见证人" + "失败会失去再立目标的资格"。两处均已修正 ——
> ① 见证席以**受邀熟人 + 公开召集**为主，陌生人当见证席 **v1 不开放**（见 `需求规格.md` R5.9 / `设计说明.md` D5.18）；
> ② 失败**不会**剥夺再立资格，只扣信用分；扣到 45 分进入「受限档」，仍可立 7 天小 Flag 自救（见 `需求规格.md` R8.5）。

  - **立 Flag 四步 → 三步** —— 「押多少」和「交押金」合并成「**③ 确认并支付**」（账户余额并进损失卡、删掉「押金区间明细」、支付方式与打钩确认搬进来）；`createPay` 页面与路由删除
  - **点「确认支付」弹二次确认** —— 「交完这一笔，你的承诺就公开生效。接下来有 24 小时可以找见证人 —— 见证人是来监督你的，不会影响你的目标能不能达成。」**这一句是整个产品的核心信任机制，必须在付钱那一刻说**
  - **目标详情：日历默认收起**（折叠头写「打卡日历 · 17/30 天 · 断 0 次」）+ **留言改成轮播的流动文字**（预览真实留言，右下角「2/3 ›」既是进度也是入口）
  - **验证**：`demo/跑全部校验.js` **23 个脚本全绿**（新增 `_verify_r224.js` 7 组断言）；浏览器实测通知行高、「全部已读」角标清零、单条已读、日历折叠展开、留言轮播轮转、三步立 Flag 到二次确认弹窗
- **2026-11-26 ⭐⭐⭐ 取证体系大幅精简：删掉身份核验这一整层** —— 九项联动改动：
  1. **删除首次认证环节** —— 发起时不再拍「起始称重物证」，**起始体重改为纯手填**；打卡照不再要求人脸
  2. **视频认证全局删除** —— 随机挑战视频（L3）功能 / 入口 / 文案 / 流程 / 数据集合（`challenge`）全部移除
  3. **L1 自动数据采集删除** —— 微信运动步数、屏幕使用时长不再作为取证层
  4. **L2 打卡照改为仅两项** —— 「同一件参照物」不再是硬性要求，硬门槛只剩**体重秤读数 + 手写随机词**
  5. **哈希校验机制删除** —— pHash 感知哈希、原图 SHA-256 唯一索引、账号哈希前缀全部移除；服务端水印只保留**时间 + 编号**
  6. **见证席 V1–V4 等级体系删除** —— 不再按累计见证量分层；资格只看**成立率 ≥ 80% + 无累计 3 次未响应**
  7. **健康底线三项删除** —— 准入门槛（年龄 / 目标体重下限）、过量减重取消资格（按周期 12%/18%/24%/30%）、触底判负一并移除；失败原因从四种收敛为三种
  8. **合规与隐私口径同步** —— 隐私政策公开内容不再含「人脸」；去掉「补交视频」自证通道
  9. **文档编号留空号位** —— 删除的章节不重排编号（沿用本项目既有惯例：R7 / R9 / R18 / R2.17–R2.19 已是空号位）

## 三条设计约束（2026-11-16 起为「两条硬约束 + 一条已推翻」） 

> **⚠️ 第一条「无评论」已于 2026-11-16 推翻**，改为「受控留言板」—— 留言有，但**只有目标人可见，围观者之间互相看不见**。见 `需求规格.md` R14 节。

| 约束 | 内容 | 为什么 |
|---|---|---|
| **有押金，但无资金池** | ⚠️ 2026-11-18 改为**区间制**（2026-11-16 起为做押金，v1）：可选区间 = [周期下限, min(信用上限, 周期上限)]；达标 100% 全退、失败按信用等级扣 20%–40%、**第一个 Flag（7/14 天）免费**。<br>**但绝对不做**：资金池、围观者瓜分、提现、**平台从押金中盈利**、宣传"稳赚" | 押金是**履约保证金**，与"资金池 + 瓜分"是不同结构。但押金归集到平台一般账户用于经营会触发长租公寓判例（本金 + 占用利息全额返还），且「失败质押分给有效判定者」是赌博结构翻版 |
| **无公开评论区** | ⚠️ 2026-11-16 改为「**受控留言板**」：有留言，但**仅目标人可见**，围观者之间互相看不见；≤50 字、限条数、内容安全审核 | **网暴之所以成立是因为有"观众席"。我们的留言没有观众席** → 攻击场、广告场、攀比场、刷屏场四个退化路径全部被堵死 |
| **只做减肥体重** | 不做通用打卡、不做饮食记录、不做健身课程 | 减肥有客观物证（体重、围度、称重照片），通用目标只有自报，做出来必然退化成"点一下就算"；且减肥有终局性动机，作弊强度高一个数量级 |
